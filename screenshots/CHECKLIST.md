# Screenshot checklist

Capture genuine screenshots from the actual application run and save them in
this folder. Do not use mock or fabricated outputs.

- [ ] Project folder structure in VS Code / File Explorer.
- [ ] Dataset loaded into a Spark DataFrame.
- [ ] Spark DataFrame schema.
- [ ] Missing-value analysis.
- [ ] Data cleaning, split, and preprocessing output.
- [ ] StringIndexer, OneHotEncoder, VectorAssembler, and scaler pipeline.
- [ ] Logistic Regression training in the terminal.
- [ ] Gradient-Boosted Trees training in the terminal.
- [ ] Actual model evaluation metrics from `outputs\model_metrics.json`.
- [ ] Confusion matrix from `outputs\confusion_matrix.png`.
- [ ] ROC curve from `outputs\roc_curve.png`.
- [ ] Actual versus predicted purchases.
- [ ] Streamlit dashboard overview.
- [ ] Customer segmentation dashboard.
- [ ] Interactive session prediction result.
- [ ] Final successful end-to-end project execution.
- [ ] University-approved plagiarism-check result, if required by the course.

The source dataset does not contain age or explicit past purchase counts. Do not
create screenshots claiming those measurements are available.
